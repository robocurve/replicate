# Through a Glass Darkly: figure replicates

Data and code to regenerate the figures of the RoboSpoof paper (spoofed camera feeds on the YAM rigs).

| Figure | Folder | What it shows | Regenerated file |
|---|---|---|---|
| conditions | `figure-conditions/` | one trial frame per scene under three conditions (normal, spoof, blur) | `paper-figures/glass-darkly-conditions.png` |
| refusals | `figure-refusals/` | refusal counts and rates per task, model and condition (normal, blurred, doctored) | `paper-figures/refusal_heatmaps.tex` + `refusal_counts.tex` |
